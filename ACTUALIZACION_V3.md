# Descenso.cl — actualización visual V3

## Qué corrige
- La portada destacada ya no superpone los títulos al texto de las imágenes SVG. La imagen se presenta en un bloque independiente y la información en otro.
- Titulares adaptables en computador y celular.
- Las páginas individuales ya no repiten el resumen cuando coincide exactamente con el primer párrafo.
- Se regeneraron las nueve páginas y el sitemap sin modificar las URLs.

## Qué no hace
- No incorpora fotos de terceros sin licencia.
- No inventa párrafos para ampliar noticias breves.
- No cambia credenciales ni configuración de GitHub/Cloudflare.

## Instalación
Copiar el contenido del ZIP a la carpeta del repositorio local (sin borrar .git), revisar en GitHub Desktop y publicar mediante Commit y Push. Conviene conservar la versión anterior para revertir en caso de problemas.
